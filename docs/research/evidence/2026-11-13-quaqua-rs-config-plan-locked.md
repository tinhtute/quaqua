# Team config: one user-owned source (roster + farm layout)

## Goal
- outcome: Changing a kind's harness, model, effort or use_for/avoid, the routing default, the active profile, or the farm layout (built-in preset choice, custom layouts, depth, caps) is one edit in anh iu's own `team.local.toml`. The engine ships `team.default.toml`; the effective config is default merged with local. No engine PR, rebuild, or markdown edit is needed; `init --update` never reverts or conflicts on the edit; the next spawn (including spawns by running Leads and pipelines) obeys it.
- success_signal: In a workspace on the new binary, set `kinds.suhuynh.model` in `team.local.toml`. Then `quaqua config get kinds.suhuynh.model`, `quaqua roster`, and the next `quaqua worker spawn` launch command all show the new value; `git -C ~/Lab/quaqua status --short` is empty; `quaqua init --update` prints no `overwrite` or `conflict` line for `team.local.toml`, and (after the R3 migration) no line for `team.toml`.
- actors: anh iu (edits `team.local.toml`); CoS and Leads (read `quaqua roster` to route); `quaqua worker spawn`, `lead spawn`, `taskforce`, `pipeline` (read the effective config and layout); the auditor; a future GUI (writes the same local file, NG2).
- authority: anh iu decisions 2026-11-13 recorded in `## Map` (Q5, Q6, Q7, Q9, Q10; GUI parked NG2); research raws `raw/2026-11-13-quaqua-rs-{q13-roster,q2-initupdate,q8-layout}.md`; `projects/quaqua-rs.md` Vision ("`team.toml` is the single config source"); `crates/quaqua/src/init.rs` reconcile rows 1–5; `crates/quaqua/src/config.rs:504,654`.
