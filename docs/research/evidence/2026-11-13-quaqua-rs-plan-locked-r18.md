# Harness, Loop and Graph: the enhanced edition of agent engineering with a Chief of Staff

## Goal
- outcome: quaqua is rewritten as a new crate beside the old one in ~/Lab/quaqua and swapped in with one main merge. A long-running farm daemon is the hub: the CoS or a Lead on herdr fans out workers across any harness (claude, pi, agy, opencode, codex later, others) chosen per kind; the daemon owns dispatch, liveness, one home for state, event-driven journaling, the fence, the task DAG and gardener schedules, and the CLI is its client. Harness, model, effort, roster and topology are data in a SQLite config: `quaqua init` seeds it from toml, edits go through `quaqua config set` / `rename-kind`, `quaqua config export` dumps toml, engine default changes surface via `config diff`. A new harness runs through a generic driver with no rebuild. Graph = task DAG + agent topology graph (spawn/mail/report edges, peer mail allowed only on edges) + code knowledge graph. KB = zbrain plus the code KG, read-only for workers. Inner loop = workers running one merged pstack/monoharness set injected per driver. Outer loop = gardener jobs: conversation scoring, rule/skill proposals (anh iu-gated), static-analysis checks, and the auditor. omp and the kind sude are gone.
- success_signal: On a workspace seeded from a copy of `~/quaqua`, one real task runs end to end on the new binary: brief, fanout to at least 2 different harnesses, cross-harness review, gate, merge into the task's project integration branch, with every kind, harness, model and effort read from SQLite. In the same run: (a) one harness is added with `quaqua config set` only (no rebuild) and `config export` round-trips to an equivalent config; (b) at least 2 dependent tasks run in DAG order, one spawn or mail off the topology is refused by the daemon and journaled, and a worker answers a query from the code KG; (c) a gardener job scores that run's worker conversations and files at least one rule/skill proposal awaiting anh iu; (d) a non-claude worker's `git push` or out-of-band spawn is blocked (native hook or daemon) with evidence. (anh iu grill 2026-11-13)
